每份包都包含自己的 package.json、依赖锁文件、页面源码、接口、数据库迁移、公开资源、运行文档和AGENTS.md。共享组件与后端保留，因为账号审批、门店位置、活动、金币、优惠券和核销相互依赖；这是三个固定入口版本，并未把业务拆成三个互不关联的后端服务。共享源码保留也避免直接删除单体组件导入而造成缺文件。

各副本的`lib/project-edition.ts`固化PROJECT_EDITION，不由查询参数、角色偏好或网页开关决定。打包时只保留该端的app页面路由；客户端不展示商家或运营入口。初次加载、刷新、浏览器返回和内部导航都按本端限定，工作台不处理客户端quest深链接。商家和运维登录页不再显示通向其他角色的“返回入口”；品牌返回本端，已登录时回本端概览。

页面范围不是后台授权。所有版本继续使用原服务端账号、角色、审批、封禁和商家门店校验；隐藏其他页面不会赋予权限，也不允许通过修改请求选择其他门店。玩家注册必须验证邮箱并以邮箱密码登录；昵称可选并提示默认名称；商家注册仍提交真实地址、WGS84位置、范围和首券，新商家/运营须审核。

本版修复旧页面身份标识导致无法登录的问题：明确的密码登录与已获本机权限的录制快捷登录可以切换当前账号，登录后重新核对实际身份。领奖、核销、投稿及注册保留原身份校验；录制快捷入口继续受后端本机地址与私有开关控制。专属版本还优先拦截跨端原生后退，防止误入其他端的404页面。

商家和运营工作台的窄屏菜单还有左右箭头提示，表示对应方向有隐藏内容；可以横向滑动或点击箭头，滑到边缘后隐藏相应提示。图标为16px、点击区域44px，箭头浮在菜单两端的上层，不再挤占菜单宽度或留下占位空隙；客户端底部导航沿用原结构。

## 分别运行

解压后进入对应的mall-quest目录，使用Node.js 22.13或更新版本，执行`npm run install:ci`。首次复制`.env.example`并填写自己的私有配置；首次创建本地库运行`npm run db:local`，再`npm run dev`。构建使用`npm run build`。更新已有项目必须先备份实际数据库，增量应用尚未执行的迁移至0015（共16个迁移文件、28张应用表），不能用新空库替换业务记录。发信配置及完整运行说明见README.md和运行说明.md。

每份源码在自己的目录启动时，默认使用自己的`.wrangler/state`。三个独立数据库不会自动同步，所以不能将三份空库独立启动后认为商家申请、审核、领奖和核销已经联动。包中不包含原本机数据库、任何私有配置或账号密码。

若在一台电脑上同时启动，不同端口仍会共享同一主机的同名Cookie。独立数据库演示请使用独立浏览器配置/不同主机名，并为每个进程设置不同监听端口，避免会话混用。这里没有更改现有Cookie名称，也没有新增网页录制开关。

## 三端联动部署

当前请求继续访问同源`/api/game`、`/api/creator-draft`及地图/硬件接口，没有新增跨域API地址配置或放宽CORS。部署时应使用同一公开站点、共享接口服务与持久数据库，将三端页面按路径分发；必须同时处理各构建的静态资源和服务端渲染资源，不能只上传静态HTML或让一个入口吞掉其他两端。此处说明部署要求，没有在用户服务器配置反向代理或数据库共享。

Cloudflare部署若使用多Worker，须正确绑定同一D1实例并保持授权配置一致。现有华为云宝塔演示使用本地Worker持久目录；三个默认独立的Wrangler目录不能替代共享数据库服务。若暂时只使用一个宝塔进程，继续使用完整合并项目承载三端最稳妥。多进程联动需部署者配置并验证，不能由源码ZIP自动完成。

硬件二维码、NFC标签和任务分享应指向客户端的公开HTTPS地址及正确领取路径。商家核销接口可以由共享服务处理，但商家/运维页面地址不能用作玩家NFC领取页。手机定位及网页内NFC能力仍受HTTPS和设备支持约束。

录制快捷入口继续由原服务端RECORDING_SHORTCUT_LOGIN控制；公网不开启，本包不含原本机私有开关。具体保留、关闭和移除范围见录制模式说明.md。

最新功能与验证以技术架构.md为准；压缩包根目录交接说明和文件清单用于检查版本及逐文件SHA256。安装依赖、构建产物、数据库和私有变量不随源码交付。
