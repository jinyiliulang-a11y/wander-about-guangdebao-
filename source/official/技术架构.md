# 逛道宝官网技术架构
版本：1.0.3；最后更新：2026-10-04（Asia/Shanghai）。

## 范围与技术
React 18、TypeScript、Vite 6、React Router、Tailwind 的独立静态官网，沿用 npm 锁文件。
官网介绍产品、团队和个人联系方式；账号授权、数据库及奖励业务由产品服务提供。
当前产品源码与架构为 v2.3.48，产品已经独立完成构建与部署。

## 页面与内容
Home：品牌定位、五步 NFC 主流程、三端职责、两张 PPT 设计图和可选真实视频。
Product：功能说明；ProductDetail：落地准备、试点步骤、场景与责任分工。
Team：四位成员、彩色照片、独立简介抽屉和已确认个人邮箱。
Contact 重定向 /team#contact；没有咨询假提交或未接后端的订阅功能。
设计图标注“产品界面设计展示”，商业目标不写为真实业绩。
视频配置为空时不展示假播放器；正式视频仍待用户提供。

## 地址、资源与导航
官网地址固定 https://your-server.example.com/official/ ，未改名或改变路径。
Vite base 与 BrowserRouter basename 均使用 /official/；资源根据 BASE_URL 拼接。
内部页面使用 Link；所有体验产品链接使用普通 a，默认 https://your-server.example.com/。
公开变量为 VITE_SITE_BASE、VITE_PRODUCT_URL、VITE_PRODUCT_VIDEO_URL、VITE_PRODUCT_VIDEO_POSTER。
浏览器公开配置不放私有凭据；生产不生成 sourcemap，定位插件仅在开发启用。
产品角色入口与登录页提供返回 /official/ 的链接，业务页面通过已有返回首页进入角色入口，不重复放按钮。
返回不退出账号，受保护操作保留导航等待提示；正常点击160ms轻退场，减少动态直接跳转，修改键保持原生行为。
Nginx 页面刷新提供 SPA 回退，缺失静态资源返回 404，产品 API 与 NFC 深链接保持原路由。

## 首页动画（1.0.2）
参考苹果官网的分节滚动节奏，保留现有品牌与内容；没有引用苹果代码或素材。
每个元素只保留一次入场，移除嵌套 reveal、首屏图片入场与流程节点的重复位移。
首屏文本错峰淡入，桌面 760ms、手机 580ms；双产品图整体只做一次透明度入场。
桌面在支持 CSS view-timeline 时，两张产品图随首屏退出视口产生不同幅度的轻微纵向位移，
流程细线随章节滚动展开，均使用 transform；没有 JS 每帧状态或额外滚动监听。
手机不运行持续视差；不支持 timeline 时展示静态完整产品图和流程线。
useScrollReveal 随 pathname 重新观察并清理；默认内容可见，仅观察器准备的元素进入等待态。
键盘聚焦立即显现目标及上层内容；缺少 IntersectionObserver 或 matchMedia 时直接完整显示。
支持现代和旧 MediaQueryList 监听接口；减少动态效果设置取消入场、视差和抽屉滑入，
运行中切换到减少动态效果也立即揭示内容。没有无限旋转、持续漂浮或首页大面积模糊动画。

## 团队抽屉与照片（1.0.2）
createPortal 将原生 dialog 挂到 body，桌面右侧、手机底部显示，不参与卡片网格布局。
保持背景滚动锁和滚动条占位；长简介在抽屉内滚动。
整块面板以420ms平顺滑入：桌面从右侧100%移到原位，手机从底部100%移到原位，没有启动延迟。
面板及照片文字始终不透明；内容没有独立位移、动画或延迟显现，只随面板整体移动。
遮罩同时以300ms淡入，移除实时背景模糊；关闭时整块面板与遮罩均以320ms收回。
提前关闭捕获面板位移与遮罩透明度的当前帧；退出保留模态、滚动锁和焦点，完成才卸载，400ms有界兜底；重复关闭执行一次。
仅存活的面板使用will-change:transform；减少动态效果时取消所有动画及该提示。
退出中切换减少动态效果立即完成，SPA离开清理监听与计时器。
支持关闭按钮、Esc、遮罩点击与模态内 Tab 循环，关闭后焦点回到原触发按钮。
照片保持彩色。姚宇轩卡片和抽屉均用 object-position:50% 65% 对准原图人脸，未修改原照片。
个人邮箱只使用已确认成员资料，mailto 不自动发送邮件。

## 业务说明边界
地图线索 → 金币 NFC 与到店校验 → 保存申请 → 商家核对设备、玩家与实物 → 确认奖励 →
优惠券进入个人卡包或积分入账 → 日后凭个人券码核销。普通观察题另走答题领奖流程。
金币设备码用于识别，不等于单次个人券；角色界面切换不授予后台权限。
产品已实现圆形与多边形围栏，0016 迁移已部署；此前 WorkBuddy 交接报告称 JS SDK 与隔离围栏保存通过。
本轮真实 Web 服务仍返回10009，POI 与手机现场定位未由本批完成可用性验收。
当前地图代理不再立即 503，但实测高德返回 USERKEY_PLAT_NOMATCH/10009，不写为地图可用。
没有已证实的转化增长、百万并发、Beacon、运行时 AI 或真实完整现场核销验收结论。
